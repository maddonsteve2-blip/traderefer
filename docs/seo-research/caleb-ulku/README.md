# Caleb Ulku AI SEO Research Notes

This folder stores TradeRefer research notes from Caleb Ulku videos about local SEO, AI SEO, Google Maps, AI Overviews, and entity-based content architecture.

The goal is not to copy full transcripts into the repo. Raw transcripts are useful for private analysis, but the repo should keep decision-ready summaries, source metadata, and actions for TradeRefer.

## Storage Model

- `videos.json`: source inventory, selected videos, transcript status, and why each video matters.
- `notes/`: timestamped digest notes for each selected video.
- `raw-transcripts/`: local-only holding area if raw transcripts are ever needed. This folder is ignored by Git except for its README.
- `traderefer-ai-seo-plan.md`: TradeRefer-specific plan refined from the research and current GSC data.
